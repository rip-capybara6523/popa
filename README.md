setting.py — Глобальні налаштування. Містить константи гри: розміри екрана, характеристики котів та ворогів, вартість покращень, кольори та універсальну функцію для безпечного завантаження й масштабування картинок.

base.py — Базовий клас персонажів. Тут описано загальну логіку для будь-якого рухомого юніта в грі (Unit): рух, отримання шкоди, перевірка чи він живий та відображення на екрані.

cats.py — Бойові коти та снаряди. Відповідає за специфічну логіку союзних сил: далекобійного кота (RangedCat), який вміє зупинятися для стрільби, та поведінку куль (Bullet), які летять у ворогів.

enemies.py — Логіка ворогів. Містить алгоритм вибору типу ворога (choose_enemy_type), який вирішує, кого саме спавнити залежно від залишку здоров'я бази та того, чи вийшов уже фінальний бос.

ui.py — Елементи інтерфейсу та бази. Описує клас Base (бази гравця та ворога), їхнє відображення на екрані та зелені смужки здоров'я (HP-бари) над ними.

main.py — Головне серце гри. Зв'язує всі модулі докупи. Керує запуском вікна, ігровим циклом (оновлення кадрів 60 FPS), обробкою натискань клавіш, нарахуванням енергії, колізіями (сутичками) між юнітами та виведенням меню на екран.
